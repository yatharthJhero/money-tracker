# Money Tracker

A local-first Android app exploring a simple question: how can people understand their everyday spending without having to manually maintain a detailed ledger?

## Current stage

**Stage:** Early MVP foundation  
**Status:** No app features implemented yet  
**Platform:** Android  
**Language:** Kotlin  
**UI:** Jetpack Compose (planned)  
**Storage:** Room / SQLite (planned; confirm during implementation)

## First milestone

1. Create and run the Android project.
2. Add an expense.
3. Persist expenses locally.
4. Show transaction history.
5. Show simple category totals.
6. Verify data survives app restart.

## Product principles

- Local-first by default.
- Explicit user consent and control.
- Never request UPI PINs, OTPs, bank passwords, CVVs, or card credentials.
- Do not claim complete transaction capture.
- Show uncertainty honestly.
- Keep the first version small and testable.
- Do not send personal financial data to an AI service by default.
